# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in every project space (issues, pull requests, reviews and any
other place the project runs) and when someone represents the project elsewhere. The text is not
copied here; the linked page is the authoritative version.

## Reporting

Report unacceptable behaviour privately to the maintainer. Open an issue that asks for a private
contact and says nothing else: no names, no quotes and no description of what happened. The
maintainer will reply with a private channel, and the report continues there. For content that
breaks GitHub's own rules, you can also use GitHub's reporting tools.

Every report is reviewed, and the reporter's identity is kept confidential. The maintainer applies
the enforcement guidelines of the Contributor Covenant.

One project rule belongs here too: never post real meeting content, recordings, transcripts, names
or identifiers anywhere in the project. If you come across any, report it so that the maintainer
can remove it.
